# Админ-панель

Адрес: **https://ваш-сайт.ru/admin**

## Вход
- Логин и пароль задаются в `admin/auth.php` (константы `ADMIN_LOGIN` и `ADMIN_PASS`).
- **Обязательно смените пароль** перед выкладкой на хостинг (пароль не должен быть admin123).

## Возможности
- Редактирование всех текстов сайта (SEO, блоки 1–6, футер, cookie-баннер).
- Редактирование подписей и путей к изображениям.
- Карусель: добавление/удаление фото, изменение порядка и подписей.
- Проекты: добавление новых проектов, обложка, загрузка фотографий в галерею проекта.
- Загрузка изображений через форму (ограничение: JPG, PNG, WEBP, GIF).

## Требования
- PHP 7+ на хостинге (например SpaceWeb).
- Права на запись в папки `data/` и `uploads/`.

## Защита
- Доступ к админке только после авторизации (сессия).
- В `admin/upload.php` разрешены только типы файлов-изображений.
